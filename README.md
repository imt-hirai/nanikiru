# 麻雀 何切る 200問

ブラウザで遊べる麻雀の「何切る」問題集です。赤ありのMリーグルール（Mリーグ準拠）で 200 問、各問題に **1〜3位の順位付け** と理由が付きます。

## 特長

- 全200問（テンパイ50 / 1シャンテン80 / 2シャンテン70、3〜14巡目に分散）
- 赤ドラあり（赤5萬・赤5筒・赤5索 各1枚）、25,000点持ち
- 牌は Unicode の麻雀牌（U+1F000〜）で表示（赤5は赤色＋「赤」マーク）
- **4家の河（捨て牌）・副露（ポン/チー）・リーチ**を表示（河は捨てた順、横向きの牌がリーチ宣言牌・鳴かれた牌）
  - リーチ局面（全体の40%）、副露あり局面（20%）、静かな局面（40%）を出題
- 局面条件を明示
  - 半荘の風・局（東1局〜南4局）、本場、供託
  - 親 / 子、自風、場風
  - 巡目
  - 4名の現在得点（自分・下家・対面・上家、順位と自分との点差付き）
  - ドラ表示牌とドラ
- 打牌を選ぶと **1位〜3位の打牌**、シャンテン数・受け入れ枚数・打点目安・和了率目安・放銃率目安・期待収支・理由を表示
  （「全ての打牌の評価」で全選択肢も確認可能）
- 成績（1位一致率など）はブラウザの localStorage に保存

## 必要なもの

- Python 3（macOS 標準の `python3` で動作確認済み。追加ライブラリ不要）
- make

## 起動・停止（make コマンド）

```bash
make start     # 起動（バックグラウンド）  → http://localhost:8081/
make stop      # 停止
make restart   # 再起動
make status    # 起動状態の確認
make open      # ブラウザで開く（macOS）
make logs      # サーバーログの表示
make generate  # 問題を再生成（web/problems.js を上書き）
```

- ポートを変える場合: `make start PORT=9000`
- PID は `.run/server.pid`、ログは `.run/server.log` に保存されます。
- 他端末から使いたい場合は `make start HOST=0.0.0.0`

## 使い方

1. `make start` を実行し、ブラウザで <http://localhost:8081/> を開く
2. 局面（局・本場・親子・巡目・各家の点数・ドラ）を確認する
3. 手牌（13枚＋ツモ牌）から切る牌をクリック
4. 判定（◎1位 / ○2位 / △3位 / ×圏外）と、上位3つの打牌・理由が表示される
5. 「次の問題へ」で進む。上部のプルダウンで問題番号を指定、「未回答からランダム」も可
   （キーボードの ← → でも前後移動）

得点は 1位一致=3点 / 2位=2点 / 3位=1点 で集計されます。

## 前提とルール

- 自分は門前・立直を前提に評価します（自分の手は鳴きません）。他家はリーチ・副露あり
- 他家の河・副露は無作為に生成した「それらしい」もので、実戦譜ではありません（他家の手牌は非公開として確率で評価）
- リーグルール想定: 赤3枚、喰いタンあり、後付けあり、ダブロンなし 等
- 順位は **簡易評価アルゴリズム** による目安であり、AI（Mortal 等）の厳密な最善手ではありません

## 順位の決め方（tools/generate.py）

各打牌について次を計算し、`期待収支 ≒ 和了率 × 打点^α − 放銃リスク` の大きい順に順位を付けます。

1. **シャンテン数・受け入れ枚数**（通常形・七対子・国士無双、自分の手牌・ドラ表示牌・4家の河と副露を除いた残り枚数、2手先の受け入れも考慮。自分の河に待ちがあればフリテンとして和了率を下げる）
2. **和了率の推定**: 残りツモ回数（巡目から算出）の中で、各段階の受け入れ確率を進めたマルコフ推定
3. **打点の推定**: 立直・ドラ・赤ドラ・役牌・タンヤオ・ホンイツ/チンイツ・一通・三色・七対子の見込みから期待翻数を出し、親子別の点数に換算。本場・供託も加算
4. **放銃リスクと押し引き**: 脅威者（リーチ者はテンパイ確率100%、副露者は副露数・巡目・役の有無から推定）ごとに、打牌の放銃率を現物（0%）・スジ・字牌・残り枚数・ドラから推定。今後危険牌を切るリスクも含め、「押し続ける場合」と「降りる場合」のよい方を採用し、今の打牌の放銃損失を引いたものを**期待収支**とする
5. **点数状況補正 (α)**: 終盤（南3局以降）でトップ目＆大差なら α=0.7（速度重視）、ラス目なら α=1.3、3着目なら 1.15（打点重視）。それ以外は 1.0
6. 1〜3位が同率・僅差にならない問題だけを採用（順位が明確な問題のみ）

問題を作り直したいときは `make generate`（または `python3 tools/generate.py --count 200 --seed 好きな数字`）。
